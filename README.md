This project is a marketplace web application that I consider more or less a passion project in order to establish and demonstrate my
technical abilities. Mostly getting comfortable with Python, Django, database relationships and CRUD operations.

Frontend was developed using Django template syntax, Tailwind CSS (via CDN), daisyUI library (https://daisyui.com/)

Features: 
- User authentication and authorization
- Car listing filtering
- Car listing creation and editing
- Comment creation and editing
- User profiles
- Favorites
